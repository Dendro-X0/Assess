Assess API

Assess before you attempt.

Honeypot-aware scoring for GitHub paid-work issues — farms, exfil traps, unfunded bait, and claimed bounties. Returns a verdict, score, and signal evidence your agent or UI can act on.

OpenAPI spec

POST /v1/assess · public GitHub only · heuristic, not legal advice

Try it

Paste a public GitHub issue URL. Uses your API key from signup (this session).

How it works

Paste a GitHub issue URL → API returns verdict + score + signals → your workflow decides.

curl -s http://localhost:8787/v1/assess \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"mode":"opportunity","url":"https://github.com/owner/repo/issues/1"}'
